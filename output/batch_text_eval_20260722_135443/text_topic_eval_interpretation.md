# 九类主分类规则回归评估解读

## 1. 本批次目的

本批次用于检查：把完整九类定义、判断顺序和领域优先规则补入 DeepSeek 提示词后，已知18条无答案提示样本中的4条错例是否改善，原有正确样本是否回退。

这是一组回归样本，不是独立测试集。样本曾参与错误分析，尽管提示词没有写入具体样本词语或答案，本批次仍只能证明已知边界的回归表现，不能证明对新内容的泛化能力。

## 2. 核心结果

| 指标 | 结果 | 解读 |
|---|---:|---|
| 已标注样本 | 18 | 18条样本均有人工标准答案 |
| 有效预测 | 17 | 17条成功产出九类范围内的主分类 |
| 缺少预测 | 1 | 1条调用返回内容无法解析为JSON，没有主分类结果 |
| 正确样本 | 17 | 按全部18条计算，17条模型主分类与人工答案一致 |
| 端到端 Accuracy | 94.44% | 调用或解析失败也按未命中计算 |
| 有效预测 Accuracy | 100.00% | 仅看17条有效预测，分类全部正确 |
| 预测覆盖率 | 94.44% | 有效九分类预测占18条已标注样本的比例 |
| Macro-F1 | 96.30% | 对9个业务分类的F1等权平均；缺失预测造成体育健康类漏报 |
| 总成本 | 0.027852元 | 包含17次成功调用和1次失败调用的记录成本 |
| 平均模型延迟 | 4356.78ms | 18次真实调用的平均耗时 |
| P95模型延迟 | 10955ms | 高于文本任务原定2000ms上限 |

本批次共触发18次 `deepseek-v4-flash` 文本分析，没有图片、视频或 mock 模型调用。17个文件处理成功，1个文件处理失败，文件级成功率为94.44%。

## 3. 修改前后对比

| 观察项 | 修改前基线 | 本轮回归 | 判断 |
|---|---:|---:|---|
| 端到端 Accuracy | 77.78%（14/18） | 94.44%（17/18） | 提升，但仍受1次无结果影响 |
| Macro-F1 | 73.70% | 96.30% | 9类表现更均衡 |
| `other` Recall | 0.00%（0/2） | 100.00%（2/2） | 两条已知兜底类错例均修复 |
| 原4条错例 | 0/4正确 | 4/4正确 | 已知边界回归通过 |
| 原14条正确样本 | 14/14有结果且正确 | 13/14有结果且正确，1/14无结果 | 没有观察到语义误判，但严格端到端回归未通过 |
| 调用错误 | 0 | 1 | 响应解析稳定性出现新风险 |

第14条体育健康样本不是被分错，而是 DeepSeek 响应内容无法解析为JSON。它的 `predicted_topic` 为空，因此端到端统计按错误处理；不能用有效预测100.00%掩盖这次失败。

## 4. 分类级结果

除体育健康外，其余8个分类的 Precision、Recall 和F1均为100.00%。体育健康有2条人工样本，其中1条成功并正确，另1条没有预测，因此 Recall 为50.00%、F1为66.67%。

`other` 的两条样本都被正确归入兜底类，说明“组织通知和办事流程不能因涉及日常场景就归生活”“无法匹配前八类时可以选择其他”等规则对已知错例有效。

## 5. 评估口径修正

真实回归首次暴露了一个评估器问题：旧逻辑会把“当前数据未提供”纳入分类集合，相当于虚构第十个类别。现已修正为：

- 端到端 Accuracy 继续以全部已标注样本为分母，无结果按未命中计算；
- 有效预测 Accuracy 只衡量成功产出九类预测的样本；
- 预测覆盖率衡量有效预测占比；
- Macro-F1 只在既定九个业务类别上计算，无结果会造成对应真实类别漏报，但不会成为新类别。

## 6. 当前闸门判断

分类规则回归取得正向结果：原4条错例全部修复，17条有效预测没有语义错误，`other` Recall 达到100.00%，端到端 Accuracy 和 Macro-F1 都超过预设最低门槛。

但完整功能闸门尚未通过。原因是原来正确的第14条样本本轮没有有效预测，违反“原有正确样本不能回退”的严格端到端要求；同时预测覆盖率只有94.44%，P95延迟仍明显超过2秒目标。

因此下一步仍应留在文本主分类链路，优先加固结构化响应解析与最小重试边界。代码和离线测试完成后，如需再次真实验证，必须重新获得调用授权；本轮不自动重试失败样本。

## 7. 字段说明

| 字段 | 含义与作用 |
|---|---|
| `predicted_topic` | DeepSeek输出的主分类；本轮失败样本为空，用于区分无结果和分类错误 |
| `gold_topic` | 人工确认的正确主分类，是回归比较基准 |
| `accuracy` | 端到端准确率，以全部已标注样本为分母，无有效预测按未命中处理 |
| `valid_prediction_accuracy` | 有效九分类预测中的准确率，用于单独观察分类判断能力 |
| `prediction_coverage` | 有效预测占已标注样本的比例，用于观察调用和JSON解析稳定性 |
| `macro_f1` | 九个业务分类F1的等权平均，用于暴露弱势分类 |
| `recall` | 某个人工分类样本被正确识别的比例，用于观察漏报 |
| `processing_status` | 文件处理状态；失败样本为 `failed`，表明没有形成有效最终结果 |
| `error_message` | 技术错误信息；本轮用于定位JSON解析失败 |
| `total_cost_cny` | 本批次真实模型调用总成本，单位人民币 |
| `p95_model_latency_ms` | 模型调用延迟第95百分位，单位毫秒，用于判断尾部延迟约束 |
